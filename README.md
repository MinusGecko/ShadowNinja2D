# Shadow Ninja 2D

Proyecto inicial de plataformas y acción 2D hecho para Unity.

## Versión
Unity 2022.3 LTS (recomendado).

## Controles
- **A / D** o **flechas:** moverse.
- **Espacio:** saltar.
- **Clic izquierdo:** atacar.
- **Esc:** pausar o reanudar.
- **R:** reiniciar la escena.

## Primeros pasos
1. Instala Unity Hub y Unity Editor 2022.3 LTS.
2. En Unity Hub, selecciona **Add / Añadir** y elige la carpeta descargada de este repositorio.
3. Abre el proyecto y espera a que Unity importe los archivos.
4. Los scripts base están en `Assets/Scripts`.

## Estado
Esta es la base del proyecto. La escena jugable, los gráficos finales, animaciones, menú y niveles se irán incorporando en las siguientes etapas.
