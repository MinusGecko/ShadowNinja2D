# Shadow Ninja 2D — Godot

El proyecto comienza su migración a Godot 4. Se conserva la historia y el diseño narrativo existentes; los scripts de Unity no se ejecutan en Godot y se irán sustituyendo por GDScript.

## Primer prototipo
- Movimiento con A/D o flechas.
- Salto con Espacio.
- Ataque con clic izquierdo.
- Controles táctiles básicos en dispositivos con pantalla táctil.
- Cámara que sigue a Kairo.
- Escena inicial con suelo y plataformas provisionales.

## Cómo abrirlo
1. Instala Godot 4.x desde https://godotengine.org/download/.
2. Descarga este repositorio como ZIP y extrae la carpeta.
3. En Godot, pulsa Importar y selecciona el archivo project.godot.
4. Abre el proyecto y presiona F6 o F5 para ejecutar la escena principal.

## Estado
Este es un prototipo inicial con formas provisionales, no el juego terminado. Falta integrar combate real con enemigos, sistema de vida, coleccionables, diálogos, finales, arte definitivo, animaciones y pruebas de exportación para Windows y Android.
